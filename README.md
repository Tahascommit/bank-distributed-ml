# Distributed ML on Bank Marketing Data

Hadoop, Hive, Spark, Spark ML and Spark Streaming on the bank marketing dataset (`data/bank.csv`, 4,521 clients), to answer questions about the clients and predict who subscribes to a term deposit.

Work in progress, the full README comes at the end.
